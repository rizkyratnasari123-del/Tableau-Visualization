# Profitability of Product – Tableau Dashboard

## Project Overview

This project presents an **interactive Tableau story dashboard** analyzing product profitability, sales trends, and customer segmentation.

The goal is to transform transactional sales data into **clear business insights** that support strategic decision-making.

## Key Insights

* Office products generate the **highest sales volume** among all categories
* Profit shows a **steady upward trend over four years**
* Specific printing technology products contribute **significantly to total profit**
* Geographic and customer segment analysis reveals **regional purchasing patterns**

## Features

* Story-based dashboard navigation
* Trend analysis over time
* Product-level profitability comparison
* Geographic visualization of sales distribution
* Customer segment purchasing analysis

## Tools Used

* Tableau
* Data Visualization & Storytelling
* Interactive Dashboard Design
